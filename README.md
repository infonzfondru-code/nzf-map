# Карта выполненных работ НЗФ

Интерактивная карта проектов Национального земельного фонда. Карта отображается в HTML-блоке сайта `nzfond.ru` с помощью Яндекс Карт JS API 2.1. GitHub Pages хранит **только статические данные и файлы карты**. API-ключ Яндекс Карт хранится в настройках сайта, **не в GitHub**.

## Рабочие файлы

| Файл | Назначение |
| --- | --- |
| `nzf-map.js` | Интерфейс, загрузка GeoJSON, слои Яндекс Карт, выбор перекрывающихся объектов |
| `nzf-map.css` | Оформление карты в стиле сайта |
| `manifest.json` | Список отделов и годов, количество объектов и цвета годов |
| `2020.geojson` ... `2025.geojson` | Геометрия и семантика объектов отдела геодезии |
| `index.html` | Краткая страница репозитория (на ней нет самостоятельной карты) |

## Как устроены данные

В `manifest.json` для каждого года заданы `year`, `file`, `count`, `color`. Цвет `#RRGGBB` автоматически применяется к обводке, заливке, маркерам и цветному обозначению года в панели.

Для нового года добавьте GeoJSON с атрибутами объектов, затем добавьте соответствующую запись в `manifest.json`. Для нового отдела создайте дополнительную запись в `departments`. Геоданные не нужно добавлять в JavaScript вручную.

## Встраивание в Битрикс

```html
<link rel="stylesheet" href="https://infonzfondru-code.github.io/nzf-map/nzf-map.css?v=20261027-6">
<div id="nzf-yandex-widget" style="width:100%;min-height:650px">Загрузка карты НЗФ…</div>
<script src="https://infonzfondru-code.github.io/nzf-map/nzf-map.js?v=20261027-6"></script>
```

После обновления файлов при необходимости увеличьте значение `v` в ссылках для сброса кеша. На странице Битрикса должен быть подключён Яндекс JS API 2.1.

## Обслуживание

- Не храните API-ключ, закрытые материалы и конфиденциальные сведения в публичном репозитории.
- Проверяйте геометрию новых объектов перед загрузкой.
- Очистку старых скриптов выполняйте только после проверки нового HTML-блока на опубликованной странице.
- GitHub хранит предыдущие версии файлов в истории коммитов, даже после удаления из текущей ветки.
